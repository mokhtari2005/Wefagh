# ورود گروهی پیکره عمومی اختبار

Workflow با نام **Import public Iranian legal corpus** از مسیر GitHub Actions قابل اجراست.

- منبع: فایل‌های Markdown ساخت‌یافته مخزن عمومی SaeedAqamiri/laws-mcp که بر پایه آرشیو اختبار گردآوری شده‌اند.
- فقط اسنادی که متن ساخت‌یافته و دست‌کم یک ماده قابل استخراج دارند وارد می‌شوند.
- تمام اسناد و مواد با وضعیت `needs_review` وارد می‌شوند؛ هیچ سندی خودکار `verified` نمی‌شود.
- اسناد فاقد ساختار ماده، منبع مشخص یا متن قابل استخراج در گزارش ردشدگان می‌آیند.
- ورود مجدد idempotent است و با شناسه پایدار منبع، رکورد تکراری ایجاد نمی‌کند.
- Workflow ابتدا migrationهای موجود را روی D1 اعمال و Worker را مستقر می‌کند، سپس داده‌ها را وارد می‌کند.
- Secrets لازم: `CLOUDFLARE_API_TOKEN` با مجوز D1 Read/Write و Workers Scripts:Edit، و `CLOUDFLARE_ACCOUNT_ID`.
- اجرای دستی فقط با مقدار دقیق `IMPORT_TO_D1` در ورودی confirm انجام می‌شود.
- گزارش واردشده/ردشده به‌صورت artifact ذخیره می‌شود.

**محدودیت حقوقی:** اختبار منبع ثانویه است. همه رکوردها تا مقابله با روزنامه رسمی یا سامانه ملی قوانین و بررسی اصلاحات و نسخ، از پاسخ دستیار کنار گذاشته می‌شوند.
