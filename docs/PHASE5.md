# مرحلهٔ پنجم: پرسش‌گر آموزشی موت‌کورت

## قابلیت‌ها
- انتخاب نقش قاضی یا وکیل طرف مقابل
- پرسش‌های متناسب با پروندهٔ آموزشی تأخیر در تحویل کالا
- ارزیابی اولیهٔ ساختار پاسخ بر اساس چهار نشانهٔ متنی
- اعلام شفاف محدودیت‌ها و عدم ارائهٔ نظر حقوقی قطعی

## محدودیت‌ها
این قابلیت تولید پاسخ هوشمند یا تحلیل حقوقی مبتنی بر مدل زبانی نیست. امتیاز صرفاً بازخورد ساختاری و قاعده‌مند است و ممکن است به‌دلیل واژگان متفاوت، پاسخ خوب را کم‌امتیاز دهد یا پاسخ ضعیف را بیش‌ازحد امتیازدهی کند. برای استفادهٔ حرفه‌ای باید معیارها با استاد/وکیل بازبینی و در ادامه به ارزیابی انسانی یا سرویس مدل تأییدشده متصل شود.

## بررسی
با Node.js 22، دستور `npm run verify` اجرا شد: ۱۴۱ آزمون موفق و صفر شکست.
