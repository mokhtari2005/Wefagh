# مرحلهٔ ۸ — مدیریت رسانه و آماده‌سازی استقرار

## تغییرات
- جدول مستقل `admin_media` برای مقاله‌ها و قسمت‌های پادکست، با وضعیت پیش‌نویس/منتشرشده و قید یکتایی شناسه.
- API مدیریتی `/api/admin/media` برای ایجاد، فهرست، انتشار/خروج از انتشار و حذف پیش‌نویس‌ها.
- اعتبارسنجی سمت سرور برای متن مقاله، نویسنده، تاریخ، توضیحات پادکست، مدت و HTTPS بودن نشانی فایل صوتی.
- اتصال فهرست عمومی رسانه به محتوای منتشرشدهٔ مدیران؛ پیش‌نویس‌ها از API عمومی قابل دسترسی نیستند.
- فرم مدیریت رسانه به پنل افزوده شد.
- دسترسی بر مبنای نقش‌های واقعی موجود در دیتابیس: `academy_manager` برای دوره/پرونده و `media_editor` برای رسانه؛ `super_admin` به هر دو دسترسی دارد.
- نشست موت‌کورت اکنون می‌تواند پروندهٔ منتشرشدهٔ ساخته‌شده در پنل را نیز بپذیرد.

## اعتبارسنجی
- `npm run verify`: ۱۵۰ آزمون موفق، صفر شکست.
- آزمون‌های جدید پوشش می‌دهند: مجوز مدیریت رسانه، مخفی ماندن پیش‌نویس‌ها، انتشار عمومی، خروج از انتشار، حذف امن و رد کردن URL صوتی غیر HTTPS.

## استقرار
این تغییرات هنوز روی Cloudflare اعمال نشده‌اند. پیش از انتشار:
1. از D1 نسخهٔ پشتیبان بگیرید.
2. `npx wrangler d1 migrations apply wefagh-db --remote` را از مسیر `worker` اجرا کنید.
3. Worker را deploy کنید و API عمومی و مدیریت را با حساب‌های آزمایشی بررسی کنید.
4. رابط `site` را دوباره روی Pages منتشر کنید.
5. با حساب `academy_manager` و `media_editor` جداگانه بررسی کنید که هر نقش فقط بخش مربوط خود را مدیریت می‌کند.
