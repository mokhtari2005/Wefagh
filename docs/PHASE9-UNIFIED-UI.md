# فاز ۹ — قالب یکپارچهٔ رابط کاربری وفاق

## هدف
قالب آکادمی حقوقی فقط متعلق به صفحهٔ آکادمی نیست؛ این طراحی پوستهٔ مشترک کل اپلیکیشن وفاق است و در خانه، آکادمی، بانک پرونده‌ها، موت‌کورت، تقویم مواعد، محاسبه‌گرها، رسانه، داشبورد، حساب کاربری و پنل مدیریت استفاده می‌شود.

## تغییرات
- سربرگ چسبان با نشان وفاق و منوی همبرگری در همهٔ اندازه‌ها.
- جست‌وجوی سراسری اولیه برای دسترسی به بخش‌های اصلی.
- منوی کشویی مشترک بر اساس فهرست مرکزی `site/js/pages.js`.
- نوار ناوبری ثابت پایین صفحه در نمایشگرهای کوچک با پیوند خانه، دوره‌ها، موعدها، حساب و منوی بیشتر.
- یکپارچه‌سازی ظاهر فرم‌ها، ورودی‌ها، جدول‌ها، اعلان‌ها و کارت‌های صفحات داخلی.
- چیدمان واکنش‌گرا، پشتیبانی RTL، رعایت safe-area دستگاه‌های موبایل و فوکوس قابل‌مشاهده برای صفحه‌کلید.
- استفاده از تصویر محلی `site/assets/images/legal-hero.webp` برای بنر اصلی و کارت نقل‌قول؛ بدون وابستگی به تصاویر خارجی.

## رفتار جست‌وجو
جست‌وجوی فعلی برای تطبیق عبارت با نام بخش‌ها و مسیرهای اصلی است. این جست‌وجو هنوز جست‌وجوی تمام‌متن در متن مقاله‌ها یا پایگاه داده نیست.

## اجرای محلی
از ریشهٔ پروژه:

```bash
npm install
npm run verify
```

برای پیش‌نمایش رابط، پوشهٔ `site` را با یک وب‌سرور استاتیک اجرا کنید؛ APIها و امکانات نیازمند حساب تا زمانی که Worker و D1 پیکربندی و اجرا نشده باشند، به سرویس واقعی متصل نیستند.

## اعتبارسنجی
- `npm run verify`: ۱۵۱ آزمون موفق، صفر شکست.
- بررسی‌های JavaScript تعریف‌شده در `npm run check` موفق.

## محدودیت انتشار
این بسته به‌صورت ZIP برای بارگذاری دستی در GitHub آماده شده است. این کار به‌تنهایی کد را در GitHub یا سایت زنده منتشر نمی‌کند. قبل از انتشار، تفاوت‌ها را بازبینی کنید و مهاجرت‌های پایگاه داده و تنظیمات Worker را مطابق راهنمای استقرار بررسی کنید.
