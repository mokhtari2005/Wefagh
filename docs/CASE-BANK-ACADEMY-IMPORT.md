# بانک پرونده‌های تمرین و آکادمی وِفاق

## بانک پرونده‌ها

- منبع فعلی شامل ۲۰۷ سناریوی یکتا در ۱۵ دسته است.
- این موارد **سناریوهای فرضی آموزشی** هستند، نه آرای واقعی دادگاه.
- تمام سناریوها با نشان «سناریوی فرضی آموزشی ـ استنادها نیازمند بررسی» ارائه می‌شوند.
- شماره ماده برای استنادهای بررسی‌نشده نمایش داده نمی‌شود.
- بخش عمومی پرونده، پرسش‌های قاضی، نقاط قوت و ضعف، سناریوهای دفاع و رأی آموزشی را پیش از شروع تمرین پنهان می‌کند.
- پس از استقرار Worker، مدیر می‌تواند ابتدا برنامه ورود را بدون نوشتن در پایگاه داده بررسی کند:
  `GET/POST /api/admin/cases/import?dryRun=1` (متد صحیح برای dry-run برابر POST است).
- برای ورود واقعی، مدیر واردشده درخواست `POST /api/admin/cases/import` را ارسال می‌کند. ورود تکرارپذیر است و پرونده‌های موجود را بازنویسی نمی‌کند.
- برای کنترل وضعیت، `GET /api/admin/cases/status` تعداد کل، منتشرشده، مفقود و تغییرکرده را گزارش می‌کند.

## دوره‌های آموزشی

شش دورهٔ کاربردی جدید در کاتالوگ آکادمی اضافه شده‌اند و از مسیر عمومی `/api/academy/courses` نمایش داده می‌شوند:
1. کارگاه عملی دادرسی مدنی از دادخواست تا اجرا
2. ادله اثبات دعوا و فن ارزیابی دلیل
3. کارگاه پیشرفته لایحه‌نویسی و استدلال حقوقی
4. تنظیم و تحلیل قراردادهای کاربردی
5. دعاوی چک و اسناد تجاری در عمل
6. کاربرد عملی دعاوی خانواده
7. دعاوی کار و تأمین اجتماعی

هر دوره پنج درس متنی مستقل دارد. دو دورهٔ قدیمی‌تر کاتالوگ همچنان پیش‌نویس باقی مانده‌اند.

## استقرار و کنترل

پس از مرج شاخه به main و استقرار Worker:
- بانک پرونده‌ها: اجرای dry-run و سپس import با نشست مدیر.
- آکادمی: بازکردن `/api/academy/courses` و کنترل وجود شش دورهٔ منتشرشده.
- آزمون خودکار: `npm run verify`؛ آزمون جدید تعداد، یکتایی و اعتبار ساختاری همهٔ ۲۰۷ پرونده و محتوای دوره‌ها را کنترل می‌کند.

این تغییرات به‌تنهایی داده‌ای در D1 زنده نمی‌نویسند؛ ورود بانک به D1 نیازمند درخواست مدیر پس از استقرار است.
