# مرحلهٔ ششم: داشبورد پیشرفت دانشجو

## قابلیت‌های افزوده‌شده
- مسیر خصوصی `GET /api/dashboard/summary` برای خلاصهٔ پیشرفت حساب واردشده.
- تعداد دوره‌های ثبت‌نام‌شده، درس‌های تکمیل‌شده و درصد پیشرفت هر دوره.
- تعداد تمرین‌های ذخیره‌شدهٔ موت‌کورت، تعداد تمرین‌های امتیازدار و میانگین امتیازهای ثبت‌شده.
- پنج تمرین اخیر و پنج موعد باز آینده.
- صفحهٔ راست‌چین `#/dashboard` با حالت راهنمای ورود، حالت خالی و پیوند به بخش‌های مربوط.
- تمام پرس‌وجوهای خلاصه به شناسهٔ کاربر واردشده محدودند؛ دادهٔ کاربران دیگر برگردانده نمی‌شود.

## محدودیت‌ها
- داشبورد داده‌های ثبت‌شده را خلاصه می‌کند؛ خودش تمرین یا امتیاز تولید نمی‌کند.
- موعدها همان تاریخ‌های واردشده توسط کاربرند و محاسبهٔ خودکار مهلت قانونی نیستند.
- آزمون‌ها با SQLite محلی و محیط D1 شبیه‌سازی‌شده اجرا می‌شوند؛ اتصال به D1 زنده و استقرار Cloudflare در این مرحله انجام نشده است.
- آزمون مرورگری دستی روی موبایل و دسکتاپ انجام نشده است.

## بررسی
با Node.js 22، دستور `npm run verify` اجرا شد: ۱۴۴ آزمون موفق، صفر شکست و صفر آزمون ردشده. بررسی نحوی فایل‌های جدید داشبورد نیز به اسکریپت `npm run check` اضافه شد.
