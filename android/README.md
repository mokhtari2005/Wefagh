# اپلیکیشن اندروید آکادمی وکالت

این پروژه پوستهٔ اندرویدی رسمی برای وب‌اپلیکیشن https://mokhtari.ir است. داده‌ها و ورود کاربران از سایت اصلی استفاده می‌کنند.

## ساخت APK آزمایشی
با JDK 17 و Gradle 8.9:
`gradle assembleDebug`

## ساخت نسخهٔ انتشار امضاشده
چهار GitHub Actions secrets زیر باید در مخزن تنظیم شوند:
- `ANDROID_KEYSTORE_BASE64`: محتوای فایل keystore به‌صورت Base64
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

کلید انتشار را محرمانه و در چند محل امن پشتیبان‌گیری کنید. برای تمام نسخه‌های بعدی باید از همان کلید استفاده شود؛ از دست رفتن آن مانع به‌روزرسانی نصب‌های قبلی خواهد شد.

Workflow فایل APK آزمایشی را همیشه می‌سازد. فقط در صورت وجود هر چهار secret، APK انتشار امضاشده تولید می‌شود. APK آزمایشی برای انتشار عمومی یا به‌روزرسانی نسخهٔ انتشار مناسب نیست.
